# 测试方案与验收用例

本文供代码评审、手工验收和后续自动化使用，先确定测试方向、输入、预期与证据，不要求现在执行全部场景。

## 1. 范围与执行原则

- 常规运行保留 **100000 token 触发历史压缩**，单次用户任务最多生成模型回复20次，节点步骤最多40次。
- 当前验收不新增100万或200万token压力目标，不为凑语料反复调用模型。
- 默认优先使用现有 Node.js 内置测试、受控模型和本机HTTP服务；这些检查不访问真实模型服务。
- 需要真实模型验证的场景单独选择，不能从测试方案文档推断它已经执行或通过。
- 测试使用独立数据库、用户标识和会话。预置资料标明测试夹具，真实用户会话和密钥不作为提交样例。
- Git发布单独处理，不是执行测试的前置步骤，也不会自动触发真实模型脚本。

## 2. 当前覆盖如何理解

当前仓库有 **12个测试文件、93个自动化用例**。最近一次完整 `npm run check` 已通过类型检查、93项测试和构建，不访问真实模型。本文中的场景与覆盖标记独立于这93项结果，没有执行的组合验收不能据此标为通过。

覆盖标记含义：

| 标记 | 含义 |
| --- | --- |
| 自动化已覆盖 | 已有对应受控模型、存储或本机HTTP用例，可检查确定性的程序行为 |
| 真实机制已验证 | 以前用真实模型验证过这条机制，不代表任意自然语言表达都已验收 |
| 待场景验收 | 本文已写明输入和预期，尚未作为独立场景验证；不能写成已通过 |
| 部分覆盖 | 已有底层用例，但本行中的组合、边界或完整场景仍需按需补验 |

已有真实脚本的范围也需要区分：

- `scripts/context-smoke.ts`：用小规模资料及测试实例的8000字符阈值检查摘要、纯追问和工具追问。它没有证明真实输入跨越10万token，且不会修改正常运行的10万token配置。
- `scripts/memory-smoke.ts`：检查指定记忆ID的写入、跨会话读取、快照冻结和整理。它的读取指令明确给了ID，因此不能替代“不给ID、由模型自主按索引召回”的用例。
- 历史小说大语料脚本保留供自愿研究，不属于当前必须运行的提交验收。以前的结果不能自动算作当前版本新场景的通过记录。

## 3. 测试数据和判定方法

统一使用虚构数据，例如：

| 用户 | session | 独有标记或信息 |
| --- | --- | --- |
| A | A1 | 天气任务标记 `A1-WEATHER`，待办“明天出门带伞” |
| A | A2 | 周报任务标记 `A2-REPORT`，待办“补充本周成果” |
| B | B1 | 计算任务标记 `B1-CALC` |
| B | B2 | 项目记忆标记 `B2-PROJECT` |

记忆示例：`qing-shan-project` 的名称为“青杉项目”，索引简介仅写“已确认的部署约定与测试信息”，正文保存测试识别码“青杉-4826”和端口4317。它们是无敏感性的测试值，不是密码或真实部署参数。

预期结果在运行前固定：

- 程序行为检查状态、数据库记录、工具参数、调用关联ID及事件顺序。
- 模型回答检查事实和任务结果，允许合理措辞差异，不逐字比较整篇回答或思考过程。
- 故障路径优先用可控模型或工具注入来触发，不等待真实模型偶然犯错；注入必须标明，不能冒充模型原始输出。
- 自主决策场景不给工具名、记忆ID或期望答案。接口机制测试可以指定工具和ID，两者分开记录。
- 失败结果保留。补问、重试与诊断单独记录，不覆盖第一次结果。

## 9. 成本可控的执行方式

第一层是现有自动检查：

```powershell
npm run check
```

该命令不访问真实模型。只改测试设计文档时，无需为此重复模型验证。

第二层是按需选择少量真实场景：

```powershell
# 以下命令会调用真实模型，只有需要时手动运行
npm run smoke:context
npm run smoke:memory
```

需要抽查时，选纯对话、Todo工具链、跨会话自然召回、多窗口隔离和一次参数错误恢复即可，不要求运行整份方案。10万token生产触发线的边界优先通过模拟计数检查；小阈值测试实例必须在报告中注明，不把它写成真实10万token压测。日常无需为验收增加大语料规模。

历史 `stress:novel` 命令不在默认检查链路，也不是当前提交的必跑项。本轮不启动该脚本，不设计或执行100万、200万token语料测试。

## 11. 对外交付时如何说明

- README说明运行方式、系统设计、记忆召回与放置；本文说明测试方向、输入和验收标准。
- `test/` 提供可执行的93个自动化用例；`scripts/` 中真实模型脚本按需运行。
- `docs/PROMPTS.md` 提供开发约束和运行提示词；`docs/DECISIONS.md` 提供问题解决记录。
